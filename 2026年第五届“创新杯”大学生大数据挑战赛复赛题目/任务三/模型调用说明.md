# 模型调用说明

模型格式为 Joblib 序列化的 scikit-learn 自定义回归器。请从压缩包根目录运行命令，以保证 `src` 模块可被正确加载。

```bash
python predict_task3.py --input <待预测CSV> --output <结果CSV>
```

可选参数：

- `--model`：模型路径，默认 `models/task3_final_model.joblib`。
- `--input`：待预测 CSV，必须含 `Person_ID` 及原始特征。
- `--output`：输出 CSV 路径。

预测脚本自动完成列名标准化、时间周期编码、缺失值处理、类别编码与合法区间裁剪。`Wellness_Category` 即使存在也不会进入模型。
